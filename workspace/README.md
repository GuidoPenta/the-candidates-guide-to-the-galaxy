# workspace/

This folder holds **your** data: CV, profile, job postings, research, interview notes, offers.

- Everything here except this README is git-ignored, so it doesn't leave your computer through git. A synced folder
  (OneDrive, iCloud, Dropbox, Google Drive) or a manual copy or upload will still carry it along. See "Where your data
  actually ends up" in the main README.
- Claude creates the structure the first time you run the `galactic-job-search` skill.
- The layout is documented in `.claude/skills/galactic-job-search/references/workspace.md`.
- `dashboard.html` is generated here: open it with a double click.

Want a backup? Copy this folder to an encrypted drive. A private GitHub repo also works, but then GitHub holds your data.
