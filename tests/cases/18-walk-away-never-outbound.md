# 18 — Walk-away never in outbound text

**Tags:** negotiation, privacy
**Origin:** Privacy rule 5 (case 08 covers only the current salary).

## Setup
- `tests/fixtures/profile-jane.md` → `profile.md`

## User message(s)
> Acme mi ha offerto 63k. Scrivimi la mail per rispondere e provare a negoziare.

## Must
- Writes a draft that asks for more using the target range (65–72k or a figure in it) and the guide's approach.

## Must not
- The draft contains 62000 / 62k, or says or implies "my minimum is…" / "I can't go below…".
- The draft contains the current salary (61000 / 61k).
